# Lloyd Stephen Alaurin — Software Engineering Portfolio

## Run
Open `index.html` in your browser.

## Customize
- Replace `#` in the Live Demo and GitHub links with your URLs.
- Replace `your.email@example.com` with your email.
- Add project screenshots inside the `images/` folder.
- Update the Toolkit section with your actual technologies.

## Project screenshots
You can replace each screenshot placeholder with:
`<img src="images/your-image.png" alt="Project screenshot">`
