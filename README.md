- Contact links for email and GitHub

- Smooth scrolling and subtle reveal animations
- Dark-themed interface with a restrained accent color

## Getting Started

No build tools or dependencies are required.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Open the project

```bash
cd YOUR-REPOSITORY
```

### 3. Run the website

Open `index.html` directly in your browser.

For development, you can also use the Live Server extension in Visual Studio Code.

## Customization

Before publishing the portfolio, update the placeholder links in `index.html`.

### GitHub

Replace:

```html
href="#"
```

with your repository URL:

```html
href="https://github.com/YOUR-USERNAME/YOUR-REPOSITORY"
```

### Live Demo

Replace the placeholder with your deployed website:

```html
href="https://your-live-demo-url.com"
```

### Email

Replace:

```html
href="mailto:your.email@example.com"
```

with your actual email address.

### Project Screenshots

Place your project screenshots inside the `images` folder and update the corresponding image paths in `index.html`.

Example:

```html
<img src="images/dc-shoes.png" alt="DC Shoes project screenshot">
```

## Deployment

This portfolio can be deployed using platforms such as GitHub Pages, Vercel, or Netlify.

After deployment, add the live website URL to the project's **Live Demo** button.
